# SINTELIV — Punto de Venta Inteligente

Sistema de punto de venta PWA desarrollado por **GAM Sistemas Inteligentes**.

## 🚀 Acceso

Abre el link de GitHub Pages en cualquier dispositivo:
- **PC / Laptop:** Chrome o Edge
- **iPhone / iPad:** Safari → compartir → "Agregar a pantalla de inicio"
- **Android:** Chrome → menú → "Instalar app"

## 💾 Respaldo automático

Al cerrar la app o la pestaña, el sistema descarga automáticamente un archivo JSON con todos tus datos. Guárdalo en un lugar seguro (Google Drive, iCloud, etc.).

Para restaurar: abre la app → Herramientas → 📂 IMPORTAR → selecciona el archivo JSON.

## ⚠️ Nota importante

Los datos se guardan en el navegador (localStorage). No borres los datos del sitio en la configuración del navegador. El respaldo JSON es tu seguro ante cualquier eventualidad.
